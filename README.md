# CharMate AI

A free AI character chat web app.

## How to use

1. Open `index.html`.
2. Paste your Gemini API key.
3. Click Save.
4. Choose a character and chat.

## Free hosting

Upload these files to GitHub Pages or Firebase Hosting.

## Important

This version stores the API key in the browser using localStorage. Good for testing, not for big public production.
For a public app, use Firebase Functions or another backend to protect your API key.
